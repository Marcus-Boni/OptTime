## O cronômetro

```
$(record) OPT-014  1:23:45
```

O item fica no rodapé, pintado com a cor do projeto ativo. O relógio corre
localmente a cada segundo e sincroniza com o servidor periodicamente — o mesmo
timer que aparece na sidebar do app web.

Clique para abrir o menu: pausar, parar, trocar de projeto ou lançar horas.
