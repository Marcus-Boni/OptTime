# Fontes

Estes arquivos são os mesmos subconjuntos WOFF2 que o `next/font` gera para o app
(`src/app/layout.tsx`). Eles foram copiados para que o filme use exatamente a tipografia
do produto:

| Arquivo | Família | Copyright |
| --- | --- | --- |
| `sora-latin*.woff2` | Sora (variável, 400–800) | Copyright 2019 The Sora Project Authors (https://github.com/sora-xor/sora-font) |
| `dmsans-latin*.woff2` | DM Sans (variável) | Copyright 2014 The DM Sans Project Authors (https://github.com/googlefonts/dm-fonts) |
| `jbmono-latin.woff2` | JetBrains Mono (variável, 400–800) | Copyright 2020 The JetBrains Mono Project Authors (https://github.com/JetBrains/JetBrainsMono) |

As três famílias são distribuídas sob a **SIL Open Font License, Version 1.1**
(https://openfontlicense.org). O aviso de copyright e a URL da licença continuam embutidos
na tabela `name` de cada arquivo, como a OFL permite. As fontes não são vendidas
separadamente e não foram modificadas além do subset feito pelo Google Fonts.
