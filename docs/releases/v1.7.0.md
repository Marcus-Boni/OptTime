# v1.7.0 — Servidor MCP: aponte horas conversando com o seu agente de IA

> Notas de lançamento prontas para colar em **Configurações → Releases → Nova
> versão**. O campo `Vídeo` deve receber `remotion:ReleaseShowcaseV17`.

**Título sugerido:**
Servidor MCP Oficial, Tokens de Acesso Pessoal & API para Agentes de IA

---

Esta versão leva o OptSolv Time para dentro do editor. Publicamos um **servidor
MCP oficial** — o mesmo protocolo que o Cursor, o Claude e o VS Code usam para
conversar com ferramentas — para que apontar horas deixe de ser uma interrupção
e passe a ser uma frase no meio do trabalho. Junto vieram tokens de acesso
pessoal com escopo, uma API REST pessoal e um pacote npm publicado.

## Servidor MCP: o apontamento vai até onde você já está

O agente de IA com que você programa passa a saber o que acabou de ser
construído — e registra as horas no projeto certo, vinculadas ao Work Item do
Azure DevOps, sem que você abra o navegador.

> **Você:** Terminei a API de webhooks e escrevi os testes. Registra 2h30 no Harvest, task #890.
>
> **Agente:** ✅ 2h30 registradas em Harvest (OPT-014), Work Item #890. Total acumulado hoje: 7h30 de 8h.

- **16 ferramentas** cobrindo o ciclo completo: cronômetro em tempo real
  (iniciar, pausar, retomar, parar), lançamento manual, edição e exclusão de
  apontamentos, resumo do dia, status e submissão do timesheet, busca de Work
  Items no Azure DevOps e sugestões inteligentes baseadas nos seus commits.
- **4 recursos contextuais** (`opt-time://`) que o agente lê sem gastar uma
  chamada: projetos ativos, resumo de hoje, timesheet da semana e um guia de uso
  com as regras de negócio.
- **3 prompts nativos** que viram comandos de barra no seu editor:
  `/summarize_and_log_day`, `/audit_weekly_timesheet` e `/catch_up_missing_days`.
- **Fala como gente**: `projectId` aceita o ID, o código (`OPT-001`) ou o nome
  (`Harvest`). Se o termo for ambíguo, a chamada falha listando os candidatos em
  vez de escolher por conta própria.

## Dois caminhos de conexão, zero fricção

- **Remoto (HTTP)** — o cliente conecta direto na URL, sem instalar nada.
  Funciona em Cursor, Claude Code, VS Code (Copilot) e qualquer cliente com
  suporte a servidores MCP remotos.
- **Local (stdio)** — para clientes que só falam stdio, como Claude Desktop e
  Windsurf, publicamos o pacote **[`opt-time-mcp`](https://www.npmjs.com/package/opt-time-mcp)**
  no npm. Um `npx opt-time-mcp` e pronto.

A nova tela **Configurações → Integrações → Agentes de IA (MCP)** gera a
configuração já preenchida com o seu token, tem um botão **"Testar agora"** que
faz uma chamada real ao servidor, e traz o catálogo de ferramentas lido ao vivo.

## Tokens de Acesso Pessoal

- **Três níveis de permissão**: *Somente leitura*, *Registrar horas* e *Acesso
  completo* (que inclui submeter o timesheet). Cada agente recebe o seu token,
  com o menor escopo que resolva.
- **Validade configurável** (30 dias a 1 ano, ou sem expiração) e **revogação
  imediata** — a próxima chamada do agente já falha.
- **Só o hash é guardado**: o servidor grava um SHA-256; o valor completo aparece
  uma única vez, no momento da criação. Nem a equipe do OptSolv consegue
  recuperá-lo.
- **Auditoria**: data de criação, último uso e origem da última chamada ficam
  visíveis na tela de tokens.

## Limites que não cedem

Horas viram folha de pagamento, então o agente opera dentro de trilhos:

- O token concede exatamente o **seu** acesso — só os projetos em que você já
  está alocado, nada além.
- **Semanas submetidas ou aprovadas ficam bloqueadas**: nenhum agente cria, edita
  ou exclui horas nelas.
- **Submeter a semana exige confirmação explícita** quando há dias abaixo de 6h —
  a chamada falha listando as pendências em vez de fechar um período incompleto.
- **Timers com menos de 1 minuto são descartados** em vez de virarem lançamentos
  de 1 minuto. Trocar de projeto logo após iniciar, ou um agente reenviando a
  chamada, não inventa mais horas que não existiram.
- Limite de 240 requisições por minuto por token.

## Entrega para o agente (Agent Handoff)

Quem não quiser editar JSON na mão pode simplesmente **copiar um prompt pronto** e
colar no próprio agente que quer conectar. A instrução já vem adaptada ao cliente
e ao transporte escolhidos, com os caminhos de arquivo corretos e o passo de
recarregar a configuração.

## API REST pessoal (`/api/v1/me`)

O mesmo token pessoal autentica uma API REST enxuta, útil para scripts e
automações próprias: identidade, projetos, timer, lançamentos, resumo do dia,
timesheet, work items e sugestões. Erros vêm num envelope estável com código,
mensagem e uma dica do próximo passo.

## Correções

- **Datas resolvidas no fuso da organização.** O servidor roda em UTC, então
  entre 21h e 23h59 (BRT) qualquer "hoje" calculado no backend caía no dia
  seguinte. Agora todo cálculo de data server-side passa pelo fuso configurado.
- **Listagem de projetos avisa quando trunca.** Quem enxerga muitos projetos
  recebia uma lista cortada em silêncio; agora vem o total e um aviso explícito,
  para o agente não afirmar que um projeto não existe.
